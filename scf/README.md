# B歌单音频代理 · 腾讯云函数（SCF）部署指南

这是**最后一档方案**：腾讯云函数的出口 IP 是腾讯自己的机房，B 站不会风控国内大厂 IP，`-412` 基本不会再出现。国内手机直连，速度快、不休眠。

部署包：`bili-playlist-scf.zip`（7.8 KB，已含 WBI 签名与全部反风控逻辑，实测通过）。

---

## 费用与额度（2024-04 后政策）

- **开通不满 3 个月**：每月免费 100 万次调用 + 100 万 GBs + 2GB 外网出流量
- **满 3 个月后**：无免费额度，按量计费；**当月没有任何调用则不收费**
- 个人听歌的调用量远低于付费门槛：一首歌约 10-20 次请求（直链模式只有 1-2 次）
- 需要实名认证（个人认证即可，免费）

> 注意：直链模式下大部分流量不经过函数（音频由手机直连 B 站 CDN），只有换取地址的小请求走 SCF，外网出流量几乎可以忽略。

---

## 部署步骤（约 10 分钟）

### 1. 开通与认证

1. 打开 https://console.cloud.tencent.com/scf （未登录会先要求登录，微信扫码即可）
2. 按提示完成**个人实名认证**（免费，几分钟）
3. 首次进入可能要求开通云函数服务，同意即可

### 2. 创建函数

1. 函数服务 → **新建**
2. 按下表填写：

| 项 | 填写值 |
|---|---|
| 函数类型 | **Web 函数** |
| 函数名称 | `bili-audio`（随意） |
| 地域 | **广州** / 上海 / 北京 任选（离你近的） |
| 运行环境 | **Nodejs 18.15** 或更高 |
| 提交方法 | **本地上传 zip 包** |
| 执行方法 | 留空（Web 函数不需要） |
| 内存 | **128 MB**（足够） |
| 执行超时时间 | **30 秒**（换流+重试够用） |
| 时区 | Asia/Shanghai |

3. 代码上传：选择本地 `bili-playlist-scf.zip`
4. 高级配置无需改动（Web 函数固定监听 9000，启动脚本已写在包里）
5. 点 **完成** 创建

### 3. 配置函数 URL 触发

1. 进入函数详情 → **函数 URL**（或「触发器」）→ 开启 **函数 URL 访问**
2. 公共访问选**开启**（应用是纯前端，跨域已由代码内的 CORS 头处理）
3. 得到访问地址，形如：
   `https://bili-audio-xxxxxxxx.guangzhou.tencentscf.com/`

### 4. 验证

浏览器直接打开：

```
https://你的地址/health
```

返回 `{"ok":true}` 即部署成功。

再验证音频（换成你想听的 BV 号）：

```
https://你的地址/url?bvid=BV1anuh6aE5i&p=1
```

返回 JSON 里应有 `"ok":true` 和一个很长的 `mp4` 地址。

### 5. 回到应用配置

B歌单 → **设置 → 音频** → 代理地址填 `https://你的地址`（不带末尾斜杠）→ **测试连接** → **诊断音频** → 显示 ✓ 后选 **纯音频**。

## 包内文件说明

| 文件 | 作用 |
|---|---|
| `scf_bootstrap` | SCF 启动脚本：`PORT=9000 exec node index.mjs` |
| `index.mjs` | 代理服务（与 `server/index.mjs` 相同逻辑：/health、/url、/audio） |
| `wbi.mjs` | B站 WBI 签名（对抗 -412 风控，已用官方测试向量验证） |
| `package.json` | 元信息（无任何依赖） |

Web 函数要求：监听 `0.0.0.0:9000`、30 秒内启动完毕、响应 body ≤ 6MB —— 直链模式下响应只有几 KB 的 JSON，安全；`/audio` 流代理模式单次 Range 响应也远小于 6MB。

---

## 注意事项

**响应体 6MB 限制**
`/url` 模式返回 JSON（几 KB）不受影响；`/audio` 流代理单次 Range 分段也远小于 6MB。仅当一次性下载超 6MB 且 CDN 不支持 Range 时可能截断，现代浏览器音频播放都走 Range，无碍。

**外网出流量**
`/url` 模式响应极小，正常使用每月远低于 2GB 免费额度。

**冷启动**
SCF Web 函数闲置后实例回收，首次请求约 1-3 秒（Node 轻量，比镜像快很多），可接受。

**更换地域**
广州/上海/北京均可；距离你手机所在地区越近延迟越低。

**日后更新代理逻辑**
改完 `server/index.mjs` 后，同步复制到 `scf/index.mjs`，重新打包 zip，在函数代码页上传新 zip 即可。
